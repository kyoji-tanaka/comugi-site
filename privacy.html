Comugi のホーム

Comugi プライバシーポリシー

施行日: 2026年11月24日

Comugi（以下「本アプリ」）は、Android 用のアプリです。本アプリが扱うデータ、その使い方、保存の場所、送り先を、以下に示します。

1. 要点

  • 本アプリは、自前のサーバーを持ちません。開発者が、利用者のデータを受け取ることはありません。
  • データの送り先は、GitHub の API（api.github.com、github.com）と、Google の API（Google カレンダー、Google のサインイン・トークンの API）だけです。
  • 利用状況の解析、広告、クラッシュ報告の仕組みは、組み込んでいません。
  • 取得したデータは、利用者の端末の中に保存します。

2. 扱うデータ、目的、保存の場所、送り先

GitHub のデータ

データ使う目的端末の中の保存先送り先
GitHub のアクセストークン（サインインで発行。権限は repo・project）GitHub の API を呼ぶ端末の暗号化された保存領域（Android の SecureStorage）GitHub（api.github.com、サインイン時は github.com）だけ
Issue（題・本文・状態・期限日など）、Projects のフィールドの値一覧・カレンダー・カンバンでの表示、編集、通知、ウィジェットアプリ専用のファイル（アプリ専用の領域）GitHub に、読み取りと、利用者が行った編集の書き込み
リポジトリのファイルアプリでの表示と編集編集の最中の内容は、アプリの画面の中だけGitHub に、読み取りと、利用者が行った編集の書き込み
利用者が選んだリポジトリ・Project の指定どのデータを表示するかの設定アプリの設定（Preferences）送りません

Google のデータ（Google アカウントを追加した場合だけ）

データ使う目的端末の中の保存先送り先
Google アカウントのメールアドレス、アクセストークン、リフレッシュトークンGoogle カレンダーの読み取り。アカウントの区別端末の暗号化された保存領域（SecureStorage）Google（oauth2.googleapis.com、Google カレンダーの API）だけ
カレンダーの一覧（名前・色）と、利用者が選んだカレンダーの設定どのカレンダーを重ねるかの選択アプリの設定（Preferences）送りません
カレンダーの予定（題・日時・場所・説明・主催者・参加者の名前など）Issue のカレンダーに重ねて表示。通知。ウィジェットアプリ専用のファイルGoogle から読み取るだけ。送りません

本アプリが要求する Google の権限は、読み取り専用の calendar.readonly だけです。予定の作成・変更・削除は、行いません。

端末の中の、その他のデータ

通知の設定と、通知を出した履歴を、アプリ専用のファイルに保存します。これらは、端末の外へ送りません。

3. 第三者への提供、販売

データを、GitHub と Google への、上に示した通信（利用者の操作に必要なもの）以外で、第三者へ提供することも、販売することも、ありません。

4. Google ユーザーデータの扱い（Limited Use）

Comugi による、Google API から受け取った情報の使用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に準拠します。

  • Google カレンダーのデータは、本アプリの画面に予定を表示し、通知を出す機能を、利用者に提供するためだけに使います。
  • このデータを、広告に使いません。データブローカーなどへ、販売も移転もしません。
  • このデータを、利用者に表示する以外の目的で、人が読むことは、ありません（本アプリは、データを受け取るサーバーを持ちません）。

5. データの削除と、連携の解除

  • アプリ内: アプリ内の、GitHub と Google のアカウントの画面から、サインアウトできます。サインアウトで、そのアカウントの、端末に保存されたトークンを消します。
  • 端末の中のデータをすべて消す: 本アプリをアンインストールするか、Android の設定でアプリのデータを削除します。端末の中のデータ（トークン、Issue・予定のファイル、設定）が、すべて消えます。
  • Google との連携を解除する: Google アカウントの「サードパーティのアプリとサービス」の画面で、Comugi の権限を削除します。
  • GitHub との連携を解除する: GitHub の Settings の「Applications」で、Comugi の権限を取り消します。

GitHub と Google にあるデータ（Issue、予定など）は、それぞれのサービスのものです。本アプリは、その保管場所ではありません。

6. 変更

このポリシーを変更するときは、このページを更新し、施行日を改めます。
