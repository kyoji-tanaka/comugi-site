Comugi

Comugi（コムギ）は、GitHub の Issue を、カレンダー・リスト・カンバンで管理する、Android 用のアプリです。

できること

  • GitHub の Issue と、GitHub Projects の項目（ステータス・期限日・優先度など）を、カレンダー・リスト・カンバンで表示し、編集します。
  • Google カレンダーの予定を、Issue のカレンダーに重ねて表示します。予定の読み取りだけを行い、作成・変更・削除はしません。
  • Issue の期限や予定の開始前に、端末の中で通知します。
  • ホーム画面のウィジェットに、Issue の一覧と、週の予定を表示します。
  • リポジトリのファイルを、アプリから編集します。

使い方

アプリを開き、GitHub のアカウントでサインインします。Google カレンダーを重ねたい場合は、設定から Google のアカウントを追加します（任意）。

プライバシーポリシー

扱うデータと、その使い方は、プライバシーポリシーに書いています。
